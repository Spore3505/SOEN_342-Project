# SOEN 342 - Appointment Tracking System

## Project Overview
This project models an Appointment Tracking System for medical clinics.

The system supports patient registration, appointment scheduling,
consultations, referrals, prescriptions, and billing.

## Iteration 1 - Requirements and System Modelling

### Deliverables
1. UML Use Case Diagram
2. UML Domain Model
3. System Sequence Diagrams
4. Three Fully-Dressed Critical Use Cases
5. System Operations and Operation Contracts

### Critical Use Cases
- UC1: Book Appointment
- UC2: Conduct Consultation
- UC3: Issue Referral
